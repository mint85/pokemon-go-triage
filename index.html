Pokémon GO Triage

Build combinable in-game search strings and work a tag-based sweep, so a Pokémon is only cleared for transfer once every keep-reason has been ruled out.

The game is the source of truth. This page holds no box data: it hands you search strings to paste, and you tag and transfer in-game. No login, no automation, no risk.

      Integrity cross-check

      Your transfer pile is !KEEP. It should contain exactly the same Pokémon as negating every reason tag at once. Run both searches in-game and compare the result counts. If they differ, something got a reason tag but not KEEP (or the reverse): a keeper is at risk. This is the meticulousness guard.

      Matching counts is a strong signal, not a proof (two offsetting mistakes could still net out). But a mismatch is a guaranteed gap worth hunting down.
